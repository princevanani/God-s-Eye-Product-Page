What it does

Two engines, one goal

Most of the web's tracking infrastructure works because your browser hands over consistent, identifying details for free. God's Eye interrupts that at two separate layers.

01

Network-level blocking

Every request is checked against a tracker list before it leaves your browser, using Chrome's declarative request engine — not a script reacting after the fact.

02

Noise, not gaps

Canvas, WebGL, audio, and device signals get small, consistent noise instead of being disabled outright. A missing API is its own fingerprint — blending in works better than opting out.

03

Nothing hidden from you

A banner and popup show exactly which trackers were caught, in real time, with a one-click exception for the rare site that breaks under protection.

Under the hood

How it works

Two independent engines run on every page — one at the network level, one at the browser-API level.

The network engine

Runs before a single byte of a tracker's response reaches your machine

1
Request goes outYour browser is about to load a script, image, or pixel from a third-party domain.
2
Checked against the rulesetChrome's own request engine compares the domain against a known-tracker list — no page script involved.
3
Blocked or allowedA match is severed instantly. Everything else loads exactly as it would have.

The fingerprint engine

Runs the instant a page starts loading, before its own scripts execute

1
Page starts loadingBefore any of the page's own JavaScript runs, protective code is already in place.
2
Signals get seeded noiseCanvas, WebGL, and audio reads return consistent, slightly-off values — stable for this site today, different tomorrow.
3
A common profile, not a gapThe site sees plausible, ordinary-looking values — not a suspicious absence of data.

Being straight with you

What this can and can't promise

Most privacy tools oversell. Here's what God's Eye actually does — and the parts of tracking that no browser extension can reach.

What it does

  • Blocks known tracker and ad-network domains before they load
  • Adds consistent noise to canvas, WebGL, and audio fingerprinting
  • Normalizes device info, screen metrics, and timezone to common values
  • Shows you exactly what was caught, on every page, in real time

What it can't do

  • Hide your IP address — that needs a VPN, not an extension
  • Guarantee a "not unique" score on every fingerprint test — that level of uniformity generally requires a browser built for it, at the cost of normal site compatibility
  • Protect you if you're signed into an account — that identifies you on purpose
  • Stop a network-level or TLS-level fingerprint — those sit below what any extension can reach
