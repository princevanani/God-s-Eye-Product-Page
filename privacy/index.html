Privacy Policy

Last updated: August 2026

God's Eye is built around a simple rule: the extension that protects your privacy shouldn't need to collect any of its own. This page explains exactly what data exists, where it lives, and who can see it.

What we collect

Nothing is sent to us. There is no analytics SDK, no telemetry, no remote server this extension talks to for its own purposes. We have no account system, no logging pipeline, and no way to see your browsing activity.

What's stored, and where

The extension keeps a small amount of data in Chrome's local extension storage, on your device only:

  • Your protection settings (which categories are on, any sites you've allowlisted, any domains you've custom-blocked)
  • A randomly generated install identifier, used only to seed fingerprint noise consistently on your own device — it is never transmitted anywhere
  • A temporary, per-tab count of trackers seen on the current page, cleared on navigation

None of this leaves your browser. Uninstalling the extension removes it.

Permissions, and why

  • Read and modify data on all sites — required to inject fingerprint-masking protections before a page's own scripts run, and to block tracker requests
  • Network request observation — used locally to detect and display which trackers were caught on the current page; nothing about these requests is transmitted anywhere
  • Storage — for the local settings described above

Third parties

The extension blocks connections to known tracking domains; it doesn't establish new ones of its own. If you choose to run the optional EasyList/EasyPrivacy import, that file comes from a source you download yourself — we never fetch it on your behalf.

Changes to this policy

If this ever changes — for example, if a future version adds an optional cloud feature — this page will be updated first, and any new data collection will be opt-in.
